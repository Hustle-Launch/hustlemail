# Roadmap

## Current scope

Deliver the `notify@uncap.us` pilot through web, Linux, macOS and iOS applications. Use Resend for send/receive, finite Convex polling, persistent mailbox actions, readable email rendering and Superhuman-style keyboard interactions. Keep setup, credential handling and error reporting accurate.

## After the pilot is proven

Reassess broader domain/mailbox management, shared access, migration/export coverage, distribution updates and operational recovery using actual pilot experience. These are not advertised as shipped features. Expanding a config file alone must not enable unsupported backend scope.

## Product exclusions

No AI features, self-managed SMTP infrastructure, or Gmail/Outlook account connections are part of this roadmap. Older proposals, financial forecasts and launch claims are [archived](docs/archive/README.md).
